**Авиация становится умной**

## Слайд 4: Аналогия для понимания

**Как "обучается" машина? Простая аналогия с курсантом**

> **Обучение с учителем (Supervised Learning)** — тип ML, при котором модель обучается на размеченных данных, где для каждого примера известен правильный ответ.

| Этап | Курсант | Машина (ML) |
|------|---------|--------------|
| 1. Даем примеры | Изучает схемы ЛА, смотрит на тренажере | Получает данные X и ответы y |
| 2. Учим на ошибках | Инструктор поправляет | **Функция потерь (loss function)** |
| 3. Проверка знаний | Экзамен с новыми задачами | **Тестовая выборка** |
| 4. Реальная работа | Самостоятельный полет | Промышленная эксплуатация |

**Ключевая идея:** ML учится на *примерах*, а не на правилах.

## Слайд 8: Регрессия

**Предсказываем непрерывную величину**

> **Регрессия** — это задача машинного обучения, в которой целевая переменная является непрерывным числовым значением (например, температура, давление, время до отказа).

**Авиационный пример:**
```
X = часы наработки двигателя (0...5000)
y = остаточный ресурс (0...100%)

Цель: предсказать y по X
```

**Код (всего 3 строки!):**
```python
model = LinearRegression()      # 1. Создали
model.fit(X_train, y_train)     # 2. Обучили
y_pred = model.predict(X_test)  # 3. Предсказали
```

> **Функция потерь (loss function)** — это математическая формула, которая измеряет, насколько предсказания модели отличаются от истинных значений. Чем меньше значение функции потерь, тем лучше модель.

**Ошибка:** Чем меньше средняя ошибка (MAE, MSE), тем лучше.

## Слайд 9: Классификация

**Принимаем бинарное решение (Да/Нет)**

> **Классификация** — это задача машинного обучения, в которой целевая переменная является дискретной меткой (категорией). Модель относит объект к одному из заранее известных классов.

**Авиационный пример:**
```
Признаки: [высота, скорость, угол атаки]
Ответ:    0 = обычный полет, 1 = сваливание

Нужно: по признакам предсказать опасность!
```

**Дерево решений (Decision Tree)** — самая понятная модель:

```
      Влажность > 75%?
        /        \
      Да          Нет
     /              \
Взлет опасен     Ветер > 15 м/с?
                  /        \
                Да          Нет
                /            \
            Опасен        Безопасен
```

> **Дерево решений** — это алгоритм классификации, который последовательно задает вопросы о значениях признаков и на основе ответов принимает решение. Каждый узел дерева — это условие, каждая ветвь — ответ, каждый лист — итоговый класс.

## Слайд 10: Кластеризация

**Ищем скрытые группы (без учителя)**

> **Кластеризация** — это задача машинного обучения без учителя, в которой данные разбиваются на группы (**кластеры**) так, что объекты внутри одной группы похожи друг на друга, а объекты из разных групп — различны.

**Авиационный пример:**
У нас есть 1000 записей полетов, но мы не знаем, какие из них аварийные. Кластеризация сама разобьет их на группы:

| Группа 1 | Группа 2 | Группа 3 |
|----------|----------|----------|
| Норма | Подозрительные | Аномалия |
| 850 записей | 120 записей | 30 записей |

**Код KMeans:**
```python
model = KMeans(n_clusters=3)  # Хотим 3 группы
model.fit(X)                   # Нет y! (только X)
labels = model.predict(X_new)  # К какой группе относится?
```

> **KMeans** — это метод кластеризации, который разбивает данные на K групп, минимизируя расстояние от точек до центров их кластеров.

## Слайд 11: Жизненный цикл модели ML

**6 шагов от сырых данных до готового решения**

> **Модель (model)** — это математический объект, который после обучения способен делать предсказания на новых данных. В sklearn модель — это экземпляр класса, содержащий методы fit() и predict().

```
1. СБОР ДАННЫХ
   ↓
2. РАЗДЕЛЕНИЕ (train_test_split)
   ↓
3. ОБУЧЕНИЕ (model.fit)
   ↓
4. ПРЕДСКАЗАНИЕ (model.predict)
   ↓
5. ОЦЕНКА (accuracy_score / mean_squared_error)
   ↓
6. ВЫВОД В ПРОДУКЦИЮ (если качество хорошее)
```

**Критическое правило:** Никогда не используйте тестовые данные для обучения!

## Слайд 12: train_test_split — почему это важно?

**Аналогия с экзаменом в летном училище**

> **Обучающая выборка (training set)** — это часть данных, на которой модель непосредственно обучается. **Тестовая выборка (test set)** — это часть данных, которая не участвует в обучении и используется только для оценки качества модели на новых, невиданных ранее данных.

| Плохой подход | Хороший подход |
|---------------|----------------|
| Учим на всех задачах | 80% на обучение |
| Проверяем на тех же | 20% на экзамен |
| → "Выучил билеты, но не понял" | → "Понял физику полета" |

**В коде:**
```python
from sklearn.model_selection import train_test_split

X_train, X_test, y_train, y_test = train_test_split(
    X, y, 
    test_size=0.2,      # 20% на тест
    random_state=42     # Фиксируем случайность
)
```

> **random_state** — это параметр, который фиксирует генератор случайных чисел. Если задать одно и то же значение, разбиение данных будет одинаковым при каждом запуске, что обеспечивает воспроизводимость результатов.

## Слайд 13: ПРАКТИКУМ

**Задача:** По трем параметрам полета предсказать, будет ли турбулентность.

**Google Colab / Jupyter Notebook**

```python
# Шаг 1: Импорты
import numpy as np
import pandas as pd
from sklearn.ensemble import RandomForestClassifier
from sklearn.model_selection import train_test_split
from sklearn.metrics import accuracy_score

# Шаг 2: Создаем данные (обычно их загружают из файла)
np.random.seed(42)
n_samples = 200
altitude = np.random.uniform(0, 12000, n_samples)      # высота (м)
speed = np.random.uniform(200, 950, n_samples)         # скорость (км/ч)
wind = np.random.uniform(0, 30, n_samples)             # ветер (м/с)

# Правило: турбулентность при ветре > 20 м/с ИЛИ высоте < 2000
turbulence = ((wind > 20) | (altitude < 2000)).astype(int)

X = np.column_stack([altitude, speed, wind])
y = turbulence

# Шаг 3: Разделяем
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.2)

# Шаг 4: Обучаем
model = RandomForestClassifier(n_estimators=100)
model.fit(X_train, y_train)

# Шаг 5: Проверяем
y_pred = model.predict(X_test)
print(f"Точность: {accuracy_score(y_test, y_pred) * 100:.1f}%")

# Шаг 6: Предсказываем для нового полета
new_flight = [[8500, 800, 22]]  # Высоко, быстро, ветер 22 м/с
result = model.predict(new_flight)
print("Турбулентность!" if result[0] == 1 else "Спокойно")
```

> **Random Forest (Случайный лес)** — это алгоритм машинного обучения, который создает множество деревьев решений и объединяет их предсказания. Каждое дерево обучается на случайном подмножестве данных, что делает модель устойчивой к переобучению.

## Слайд 14: Что может пойти не так? (Ошибки новичков)

| Ошибка | Почему плохо | Как исправить |
|--------|--------------|---------------|
| **Утечка данных** | Модель видит ответы до предсказания | Честное разделение train/test |
| **Переобучение** | 100% на обучении, 50% на тесте | Упростить модель, больше данных |
| **Неправильная метрика** | Для авиации ошибки неравноценны | Использовать precision/recall для редких событий |
| **Забыл масштабировать** | Большие числа "давят" маленькие | StandardScaler |

> **Утечка данных (data leakage)** — это ситуация, когда в процессе обучения модель получает информацию, которая не была бы доступна при реальном использовании (например, данные из будущего или тестовой выборки).

> **Переобучение (overfitting)** — это явление, когда модель слишком точно подстраивается под обучающие данные, запоминая шум и случайные отклонения, и теряет способность обобщать на новые данные.

---

## Слайд 15: Переобучение (Overfitting) — главная опасность

**График-предупреждение**

Два графика — идеально проходящая через все точки кривая (переобучение) и плавная линия (норма)

**Пример из авиации:**
> Модель запомнила, что при ветре 23.475 м/с был отказ. Но ветер 23.476 м/с — уже другой случай.
> Результат: на реальных данных модель бесполезна.

**Признаки переобучения:**
- Идеальный результат на тренировке (>99%)
- Плохой результат на тесте (<70%)

**Лечение:**
- Больше данных
- Проще модель (меньше глубины дерева, регуляризация)

> **Регуляризация** — это набор техник, которые ограничивают сложность модели, чтобы предотвратить переобучение. Например, штраф за большие веса в линейных моделях или ограничение глубины дерева.

### Слайд А: Шпаргалка по метрикам

| Метрика | Формула (смысл) | Когда использовать |
|---------|-----------------|--------------------|
| `accuracy` | (Правильные) / (Все) | Классы сбалансированы |
| `precision` | TP / (TP+FP) | Важно не ошибиться ложной тревогой |
| `recall` | TP / (TP+FN) | Важно найти все отказы |
| `MAE` | Средняя абсолютная ошибка | Регрессия, понятная |
| `R²` | От 0 до 1 (чем выше, тем лучше) | Регрессия, качество подгонки |

> **Точность (accuracy)** — доля правильных ответов модели. **Precision** — доля правильно предсказанных положительных объектов среди всех, которые модель назвала положительными. **Recall** — доля правильно предсказанных положительных объектов среди всех реально положительных объектов.
